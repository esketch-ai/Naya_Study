# MULTI-GENERATION USER STORYBOARDS (다양한 연령층별 사용자 관점 상세 스토리보드 정의서)

본 정의서는 "나야~" 플랫폼이 남녀노소(男女老少) 각기 다른 세대와 배경을 가진 5인의 실제 일상 속에서 어떻게 구동되고, 기기들이 어떻게 연계 작동하는지를 유저의 시선에서 입체적으로 증명하고 검증하는 **심층 시나리오 설계서**입니다.

| :--- | :--- | :--- | :--- |

## 🎬 USER JOURNEY 01: 9세 어린이 "이민준" (아동 관점 - 놀이 학습과 부모 안심 연동)

- **상황**: 학교 방과 후 학원 버스를 기다리는 10분의 대기 시간.
- **연계 기술**: 단말기 가속도 진동 정체 감지 $\rightarrow$ 꼬마 요정 애니메이션 팝업 $\rightarrow$ 소리 매칭 퀴즈.

#### 👶 1. 꼬마 요정 요술봉 팝업 (Fairy Theme Popup View)
```
+--------------------------------------------------------+
| [02:30 PM]                          [MYSTERY FAIRY TALE] |
|                                                        |
|      (🧙‍♂️) 민준아, 마법 버스가 오기 전에!                |
|      "꼬마 요정에게 과자를 선물해볼까요?"              |
|                                                        |
|     +--------------------------------------------+     |
|     |  [ 오늘의 단어 ]                           |     |
|     |                                            |     |
|     |  Apple (애플)                              |     |
|     |  뜻: 맛있는 빨간 사과                      |     |
|     |                                            |     |
|     |  [🍎] [🍎] [🍎] [🍎] [🍎]                  |     |
|     +--------------------------------------------+     |
|                                                        |
|      [ ▶ ] 귀여운 꼬마 요정 목소리로 영어 듣기           |
|                                                        |
|      [ 🍭 사과 단어 획득하고 요술봉 흔들기 ]            |
+--------------------------------------------------------+
```

#### 📱 아동 전용 UX 연계 검증 사항:
1. **과도한 몰입 차단 (Cool-off period)**: 아동은 스마트폰 과의존 위험이 높으므로, 좀비 팝업은 하루 최대 4회를 넘지 못하도록 하드코어 캡(Cap)을 씌웁니다.
2. **부모 안심 리포트 (Parental Link)**: 민준이가 🍭 단어를 획득하거나 저녁 퀴즈를 맞출 때마다, 엄마의 카카오톡으로 **"민준이가 오늘 3개 마법 영단어를 용감하게 획득했습니다!"** 알림이 자동 전송되어 칭찬 유도 루프를 만듭니다.

## 🎬 USER JOURNEY 02: 24세 취업준비생 "최지나" (취준생 관점 - 틈새 나포 및 츤데레 퀴즈)

- **상황**: 편의점 아르바이트 중, 매대에 손님이 없어 폰 화면을 켜는 찰나.
- **연계 기술**: 조도 센서(매장 밝음) + 모션 고정 감지 $\rightarrow$ 엄격한 멘토 스파르타 카드 돌출.

#### 🧑‍🎓 2. 엄격한 코치 오버레이 (Strict Coach Overlay View)
```
+--------------------------------------------------------+
| [03:45 PM]                       [Active Voice: COACH]  |
|                                                        |
|    (🏋️) 나태함 감지! 손님 없을 때 뇌 운동 실시!         |
|    "멍때리지 말고 10초 쑤셔 넣는다!"                   |
|                                                        |
|    +----------------------------------------------+    |
|    |  [Category: INTERVIEW ENGLISH]               |    |
|    |                                              |    |
|    |  "Hit the nail on the head"                  |    |
|    |                                              |    |
|    |  뜻: 핵심을 찌르다, 정곡을 찌르다            |    |
|    +----------------------------------------------+    |
|                                                        |
|      [ ▶ ] Coach Voice (굵고 묵직한 톤으로 재생)       |
|      "면접관의 정곡을 찌르는 완벽한 표현이다. 암기해!"   |
|                                                        |
|      [ 10초 암기 완료 및 오버레이 닫기 ]                |
+--------------------------------------------------------+
```

#### 📱 취준생 전용 UX 연계 검증 사항:
1. **취업 밈(Meme) 성적 카드**: 저녁 10시 퀴즈 결과에서 오답률이 높으면 취준생 전용 뼈 때리는 조언이 나갑니다: *"이성계 조선 건국할 때 태어난 좀비 수준의 영단어 기억력입니다! 정신 바짝 차리세요."*
2. **오답 위젯 노출**: 틀린 단어는 폰 바탕화면에 독한 멘트와 함께 위젯으로 박제되어 계속 눈에 밟히게 유도합니다.

## 🎬 USER JOURNEY 03: 39세 워킹맘 "정수진" (직장인/주부 관점 - 무소음 알림과 생체 연동)

- **상황**: 회사 사무실에서 미팅 준비 중 극심한 상사 스트레스로 가슴이 쿵쾅거릴 때.
- **연계 기술**: 워치 PPG 심박수 급증(112BPM) 감지 $\rightarrow$ 폰으로 무음 로우프로필 알림 전달 $\rightarrow$ 다정한 연인 힐링 보이스 자동 스위칭.

#### 👩‍💼 3. 로우프로필 무소음 위젯 (Office Silent Widget View)
```
+--------------------------------------------------------+
| [11:15 AM]                       [Active Voice: LOVER]  |
|                                                        |
|    (❤️) HIGH HEART-RATE DETECTED (112 BPM)             |
|    "수진님, 많이 지치셨죠? 연인 보이스가 속삭여드려요"  |
|                                                        |
|    +----------------------------------------------+    |
|    |  "Let's call it a day"                       |    |
|    |                                              |    |
|    |  (💡) 오늘 일은 이만 끝내고 퇴근해요...      |    |
|    +----------------------------------------------+    |
|                                                        |
|      [ 🎧 무소음 모드: 이어폰이 꽂혀 있습니다 ]         |
|      (연인의 따뜻하고 부드러운 위로 음성 속삭임 재생)     |
|                                                        |
|      [ 마음 다스리기 및 닫기 ]                         |
+--------------------------------------------------------+
```

#### 📱 워킹맘 전용 UX 연계 검증 사항:
1. **사무실 에티켓 (Office Mute)**: 업무 중 갑작스러운 알림창 폭격은 곤란하므로, 폰이 '진동/무음' 모드이거나 업무 시간대(09:00~18:00)에는 잠금화면 전체 팝업 대신 화면 상단에 **부드러운 플로팅 토스트 배너** 형태로 최소화 노출합니다.
2. **스트레스 감쇠 힐링 연계**: 워치 심박수가 내려가면 폰 화면에 *"심박수가 평온을 찾았습니다. 고생하셨어요."* 햅틱 위로 신호를 내보냅니다.

## 🎬 USER JOURNEY 04: 72세 실버 어르신 "박옥순 할머니" (어르신 관점 - 노안 고대비 및 치매 예방)

- **상황**: 안방 소파에 누워 멍하니 TV를 보며 시간을 보내실 때.
- **연계 기술**: 스마트워치의 가속도계 20분 무모션 감지 $\rightarrow$ 치매 예방용 실버 고대비 모드 락스크린 팝업.

#### 🧓 4. 돋보기 노안 고대비 카드 (Silver High-Contrast View)
```
+--------------------------------------------------------+
| [03:00 PM]                    [돋보기 모드: 치매 예방] |
|                                                        |
|    (👵) 뇌 세포 깨우기 시간!                           |
|    "할머니, 소리 내어 영어를 따라 해보세요!"           |
|                                                        |
|    +----------------------------------------------+    |
|    |  [ 하루 필수 단어 ]                          |    |
|    |                                              |    |
|    |  Water                                       |    |
|    |                                              |    |
|    |  뜻: 시원하고 맑은 물                        |    |
|    +----------------------------------------------+    |
|                                                        |
|      [ ▶ 크게 듣기 ] (옛날 성우 음성 0.8배속 묵직한 재생)  |
|                                                        |
|      [ 👵 말하고 뇌 건강 칩 얻기 (마이크 입력) ]        |

```

#### 📱 실버 세대 전용 UX 연계 검증 사항:
1. **가입 마찰 제로 (No-Password)**: 비밀번호 없이 **전화번호 4자리 인증번호** 입력만으로 가입이 끝나도록 동선을 완전히 축소했습니다.
2. **물리 터치 방지**: 퀴즈 화면에서 손가락이 떨려 잘못 터치하는 일을 방지하기 위해, 오직 **화면 전체 스와이프 제스처**로만 보기를 넘겨 소리로 듣고 선택하도록 UI를 단순화했습니다.

## 🎬 USER JOURNEY 05: 31세 외국인 남성 "마이클" (다문화 관점 - 국어 역학습 확장 및 영어 UI)

- **상황**: 한국인 아내와 대화하던 중, 아내가 쓴 어려운 사자성어나 맞춤법을 정확히 배우고 싶을 때.
- **연계 기술**: **{나야 국어}** 채널 활성화 $\rightarrow$ 영어 베이스 UI 표기 $\rightarrow$ 한국어 올바른 발음 및 맞춤법 주입.

#### 🇺🇸 5. 다국어 역학습 카드 (Multi-Language Inverse View)
```
+--------------------------------------------------------+
| [01:15 PM]                       [Active Voice: BUDDY]  |
|                                                        |
|    (🇰🇷) INVERSE KOREAN LEARNING                         |
|    "Master standard Korean idioms in 10 seconds!"      |
|                                                        |
|    +----------------------------------------------+    |
|    |  [Category: KOREAN IDIOM]                    |    |
|    |                                              |    |
|    |  "일석이조" (Il-Seok-I-Jo)                   |    |
|    |                                              |    |
|    |  Meaning: Killing two birds with one stone.   |    |
|    +----------------------------------------------+    |
|                                                        |
|      [ ▶ ] Listen Pronunciation (Clear Seoul Dialect)  |
|                                                        |
|      [ Mark Memorized & Close ]                         |
+--------------------------------------------------------+
```

#### 📱 외국인/다문화 전용 UX 연계 검증 사항:
1. **영어 베이스 UI 스위칭**: 다국어 역학습 유저를 위해 모든 시스템 UI 언어(메뉴, 도움말)를 영어(English)로 번역 표기하되, 주입되는 학습 콘텐츠만 한국어 단어 및 한글 맞춤법으로 맵핑하는 듀얼 렌더링(Dual Rendering) 모드를 보장합니다.
2. **한국어 표준 발음 음성 피드백**: TTS는 정확한 서울 표준 억양 오디오를 전송해 외국인 유저가 억양을 완벽히 교정할 수 있도록 지원합니다.

## 🙋 마스터 검증 의견 요청

초등학생, 취업준비생, 회사원 워킹맘, 실버 어르신, 그리고 다문화 한국어 학습자까지 **5대 사용자 세부 연령대/배경 관점에 맞춘 상세 스토리보드 와이어프레임과 기기 간 정밀 연계 과정이 확립**되었습니다.

이 다양한 세대별 시나리오를 통해, "나야~" 플랫폼이 남녀노소 누구에게나 장벽 없이 동기부여를 유발하는 완벽한 서비스임을 최종 검증했습니다.

# UNIVERSAL DESIGN SPECIFICATION (전세대 통합 유니버설 디자인 설계서)

본 설계서는 7세 어린이부터 80세 실버 세대 어르신까지 남녀노소를 불문하고 모든 연령층이 아무런 기술 장벽 없이 서비스를 사용하고 두뇌를 훈련할 수 있도록 보증하는 **"나야~" 플랫폼의 전세대 유니버설 디자인(Universal Design) 표준 규격서**입니다.

---

## 1. 전세대 커버리지를 위한 3대 핵심 UX 필러 (Three Core UX Pillars)

연령대별 IT 기기 숙련도, 신체적 특성(노안, 청력 감퇴), 학습 동기 유발 요소를 고루 해결하기 위해 3가지 사용자 적응 필러를 설계합니다.

```
       +-------------------------------------------------------------+
       |                  나야~ 유니버설 디자인 코어                 |
       +-------------------------------------------------------------+
                                      |
       +------------------------------+------------------------------+
       |                              |                              |
       v                              v                              v
+--------------------------+  +--------------------------+  +--------------------------+
|  1. UI/UX 신체 적응 필러 |  | 2. 콘텐츠 지능형 분기   |  | 3. 마찰 제로(Zero) 세팅  |
|  - 큰 글씨/고대비 모드    |  |  - 아동 트랙 (기초/놀이) |  |  - 무패스워드 간편 가입  |
|  - 느린 음성/볼륨 덕킹    |  |  - 직장인 트랙 (실전)   |  |  - 워치 자동 블루투스 페어|
|  - 아동용 캐릭터 테마    |  |  - 실버 트랙 (두뇌/여행) |  |  - 직관적 전체화면 터치  |
+--------------------------+  +--------------------------+  +--------------------------+
```

## 2. 세대별 맞춤형 화면 및 콘텐츠 분기 매트릭스 (UI/UX Adaptability)

사용자 가입 시 단 **3가지의 터치 질문** 또는 연령대 판정을 통해 화면의 모든 레이아웃과 오디오 출력 사양이 실시간 동적 재배치됩니다.

### 👶 1. 키즈 & 패밀리 모드 (Kids Track: 7세 ~ 13세 아동)
- **Aesthetic (디자인)**: 좀비 비주얼이 아이들에게 공포감을 주지 않도록 **'귀여운 꼬마 유령/꼬마 요정 좀비'** 캐릭터 및 파스텔톤 컬러로 테마 자동 전환.
- **UI 컨트롤**: 미성숙한 소근육 발달을 감안하여 화면 내 버튼의 물리적 터치 영역 크기를 **최소 64x64dp 이상**으로 확대.
- **콘텐츠 및 보이스**: 초등학교 필수 영어 단어, 동물 및 사물 그림 연상 단어 위주로 배정. 오디오 목소리는 하이톤의 씩씩한 캐릭터(락스타 등)를 우선 추천하며 격려 효과음을 많이 삽입.
- **수학/과학 확장**: 구구단, 사칙연산 기초 퀴즈 및 원소 기호 대신 생활 과학 상식 카드로 자동 맵핑.

### 🧑 2. 액티브 캐리어 모드 (Active Track: 14세 ~ 49세 학생 및 직장인)
- **Aesthetic (디자인)**: 본래의 Premium Space 테마 및 Glassmorphism 고해상도 디자인 적용.
- **UI 컨트롤**: 틈새 시간을 가장 빠르게 활용할 수 있는 초고속 로딩 UI, 제스처 스와이프 기능 활성화.
- **콘텐츠 및 보이스**: 고난도 비즈니스 회화 패턴, 토익/토플 빈출 어휘, 실전 여행 영어 중심 배정. 워치 생체 정보와 100% 바인딩되어 스트레스별 최적 보이스가 실시간 변조됨.
- **수학/과학 확장**: 수능 공식, 물리 공식, 미적분, 주기율표 반응식 등 전문 입시/전공 학업용 풀 연동.

### 🧓 3. 실버 브레인 모드 (Silver Track: 50세 ~ 80세 이상 실버 세대)
- **Aesthetic (디자인)**: **노안 대응 고대비 모드(High Contrast Mode)** 즉시 실행. 폰트 크기는 기본 24pt 이상으로 자동 돋보기 스케일링, 배경은 순수 블랙에 흰색 글씨, 에메랄드 그린 포인트를 극대화하여 시각적 인지 피로도 제로화.
- **오디오 제어**: 음성 합성 속도(Rate)를 일반 속도의 **0.8배속**으로 낮추고, 한국어 설명 비중을 40%로 높인 친근한 옛날 성우 스타일 목소리 기본 매칭.
- **콘텐츠 및 보이스**: 치매 예방용 일상 두뇌 자극 퀴즈, 시니어 맞춤 실버 한마디 여행 영어 중심 배정. 
- **수학/과학 확장**: 수학 공식 대신 **'간단한 암산으로 치매 예방하기'**, **'역사 인물 맞추기'** 카드로 맵핑되어 두뇌 세포의 활성화를 노인 친화적으로 촉진함.

## 3. 전세대 유니버설 디자인 가이드라인 상세 사양 (Universal Specifications)

### 돋보기 수준의 텍스트 렌더링 규격 (WCAG AA 이상 만족)
실버 세대의 가독성을 보장하기 위해 글꼴 크기 기준선을 정의합니다.

- **Minimum Text Size**:
  - 일반 모드: 14pt (Body text), 18pt (Headers)
  - **실버/노안 모드**: **22pt (Body text)**, **32pt (Headers)**
- **Contrast Ratio (대비 비율)**: 텍스트와 배경의 명도 대비 비율을 최소 **4.5:1 이상(WCAG 2.1 AA 기준)**으로 고정하여 햇빛 아래나 저시력자도 바로 보일 수 있게 보증합니다.

### IT 마찰 제로(Zero-Friction) 접근법
어르신들과 아이들이 회원가입 및 기기 설정 과정에서 포기하지 않도록 '원터치 무설정' 기술을 탑재합니다.

1. **무패스워드 로그인 (No-Password Authentication)**:
   - 복잡한 비밀번호 설정 및 이메일 중복 확인 과정을 없애고, **휴대폰 번호 간편 인증** 또는 **카카오톡/네이버 원터치 간편 연동**만으로 가입이 즉시 종결됩니다.
2. **워치 오토 스캔 (Zero-Config Wearable Sync)**:
   - 블루투스 페어링 시 UUID나 블루투스 장치 선택 목록을 띄우지 않습니다.
   - 스마트워치가 전원이 켜진 상태로 스마트폰 반경 1m 이내에 있으면, 앱이 알아서 신호를 포착해 뒷단에서 **자동 페어링 및 센서 스트리밍 바인딩**을 완료하고 청각/시각적으로 알려줍니다: *"스마트워치가 다정하게 연결되었습니다!"*

## 4. 전세대 시나리오 기반 스토리보드 검증 (A11y & Generation Validation)

### 🧓 [실버 세대 검증] 72세 박옥순 할머니의 하루
- **트리거**: 12:30 점심 식사 후 안방 소파에 누워 휴식.
- **화면 및 오디오 작동**:
  - 폰 진동이 부드럽게 울리며 락스크린에 **36pt 크기의 큼직한 노안 모드 카드**가 켜짐: *"오늘의 치매 예방 틈새 단어"*
  - TTS 비서 목소리가 0.8배속의 인자하고 차분한 어조로 재생됨: *"할머니, 영어를 따라서 말해볼까요? Take it easy. 마음을 편하게 먹다."*
  - 할머니가 소리 나는 대로 마이크 없이 폰을 대고 말하면, 앱이 알아서 인식해 칭찬을 건넵니다.
- **결과**: 기기 조작의 두려움 없이, 손주와 대화하듯 편안한 영농 뇌 건강 습관이 성립됩니다.

### 👶 [아동 세대 검증] 9세 초등생 이민준 어린이의 하루
- **트리거**: 14:00 학교 방과 후 대중교통 이동 중 스마트폰 개방.
- **화면 및 오디오 작동**:
  - 무서운 좀비 대신 **귀여운 꼬마 요정 좀비** 캐릭터가 팝업되며 경쾌한 요술봉 효과음이 울림.
  - *"미션! 꼬마 요정에게 맛있는 과자를 주려면 다음 영어 그림을 두 번 누르세요!"*
  - 단어: *"Apple [사과]"* 카드가 귀여운 일러스트 아이콘과 함께 등장.
- **결과**: 놀이(Gamification) 요소와 훌륭한 칭찬 보상 배지가 연동되어, 억지로 하는 영어 공부가 아닌 오락처럼 습관화됩니다.

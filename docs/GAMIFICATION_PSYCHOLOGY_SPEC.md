# ADDICTIVE BRAIN STIMULATION & GAMIFICATION PLAYBOOK
## (사용자 도파민 극대화 및 초강력 중독형 게이미피케이션 심리 설계서)

본 명세서는 "나야~" 플랫폼이 단순한 학습 앱을 넘어, 사용자가 하루 중 버려지는 자투리 틈새 시간(Dead Time)마다 강력한 학습 중독과 도파민 분비(Dopamine Rush)를 느끼게 유도하는 **행동 심리학 및 게이미피케이션(Gamification) 특화 기획 설계서**입니다.

동작 심리학의 거장 닐 에얄(Nir Eyal)의 훅 모델(Hook Model)을 플랫폼 아키텍처에 완벽하게 맵핑하고, 감각 피드백(Sound/Haptic)과 B급 츤데레 랭킹 체계를 결합하여 강제로 스마트폰을 키는 것이 아닌 **"나도 모르게 다음 알림을 기다리는" 습관의 노예**로 유도합니다.

## 🔄 1. 닐 에얄의 훅 모델 (Naya~ Habit Hook Model Mapping)

"나야~"는 사용자의 뇌 속에 **"화면을 켜면 즉각적인 지적 자극과 즐거움이 온다"**는 강력한 신경 가소성 루프를 형성합니다.

```
[ Naya~ 습관 형성 훅 루프 (Habit Hook Loop) ]

          ① TRIGGER (트리거)
    ┌────────────────────────┐
    │ 내부: 틈새 지루함, 번아웃 죄책감 │
    │ 외부: 스마트 센서 좀비 팝업           │
    └───────────┬────────────┘
                │
                ▼
          ② ACTION (행동)
    ┌────────────────────────┐
    │ 초간편 10초 스와이프/발화       │
    │ (터치 한 번, 목소리 한 번 극소마찰) │
    └───────────┬────────────┘
                │
                ▼
          ③ VARIABLE REWARD (가변적 보상)
    ┌────────────────────────┐
    │ B급 츤데레 멘트, 캐릭터의 격렬한 칭찬,│
    │ 햅틱 화음, 요술봉 파티클 시각 자극      │
    └───────────┬────────────┘
                │
                ▼
          ④ INVESTMENT (투자)
    ┌────────────────────────┐
    │ 오답노트 단어 수집, 레어 성우 카드 오픈,│
    │ 부모 안심 칭찬 칩, 패밀리 카톡 자랑      │
    └────────────────────────┘
```

1. **Trigger (트리거)**:
   - *내부 트리거*: 화장실에 앉았을 때의 순간적 지루함, 대중교통 정류장에서 멍때릴 때의 시간 낭비 죄책감.
   - *외부 트리거*: 가속도/자이로 센서가 정체를 감지하고 폰 화면을 지배하는 **좀비 팝업 오버레이 및 캐릭터의 귓속말 음성 송출**.
2. **Action (행동)**:
   - 학습의 장벽을 낮추기 위해 **"딱 10초, 스와이프 단 한 번, 소리 내어 따라 부르기 한 번"**의 최소 마찰력(Low Friction) 행동 설계.
3. **Variable Reward (가변적 보상)**:
   - 매번 같은 설명이 아닌, AI 콘텐츠 엔진이 매 세션 무작위 렌더링하는 **B급 드립 밈(Meme)**과 **캐릭터 보이스의 격정적 반응**.
   - 정답 시 귀를 즐겁게 하는 **8비트 고전 아케이드 효과음**과 손가락을 자극하는 **200ms 부드러운 화음 햅틱 진동**.
4. **Investment (투자)**:
   - 퀴즈 통과 시마다 획득하는 **"브레인 칩(Brain Health Chips)"** 및 **"가사 배지(Chore Stars)"** 축적.
   - 획득한 칩으로 은밀한 연인 보이스의 특별한 꿀잠 자장가 보이스 팩, 락스타의 격렬한 모닝콜 보이스 팩 잠금 해제(Lock-open).
   - 주간 학습 오답노트에 자신이 해방한 단어 리스트가 촘촘히 보관되며 생기는 지적 수집욕 충족.

## 🔊 2. 도파민 청각·시각·촉각 마이크로 인터랙션 (Micro-Interactions)

뇌가 즉각적인 쾌감을 느끼게 하는 감각적 자극의 초정밀 하드웨어 바인딩 설계 스펙입니다.

### 🎵 A. 청각적 청량감 (Arcade Audio Feedback)
- **정답 판정 시 (Dopamine Ding)**: 클래식 패미콤 스타일의 8비트 아케이드 레벨 업 사운드(C5 ➔ E5 ➔ G5 ➔ C6 메이저 화음, 150ms 숏 톤) 재생.
- **오답 판정 시 (Witty Buzz)**: 실망감을 주기보다 유머러스한 피드백을 주는 복고풍 게임의 가벼운 카툰 스프링 사운드(뿅~ 하는 엇박자 밴딩 음원) 제공.
- **스마트워치 심박 가속 시**: AI 목소리 재생 중 백그라운드에 **이퀄라이저 음성 파동(Waveform Visualizer)**이 HSL 컬러 펄스에 맞춰 춤추듯이 출렁거려 청각이 시각으로 치환되는 감각 자극 극대화.

### 📳 B. 촉각적 햅틱 파도 (Haptic Wave)
- **정답 통과**: 모바일 햅틱 모터(`Vibrator`)의 진동 진폭을 주파수 변조하여, 마치 물방울이 손바닥 위에서 톡 터지는 듯한 **'부드러운 이중 태핑 햅틱(Short Double Tap, 80ms 간격)'**을 송출.
- **콤보 달성 시 (3회 연속 정답)**: 손끝으로 심장 박동처럼 쿵쾅거리게 울려주는 **'콤보 펄스 화음 진동(Smartwatch Haptic Pulse)'** 제공.
- **스트레스 완화 연인 모드 스위칭**: 워치가 회원님의 HRV 스트레스 스파이크를 감지하면, 폰과 워치가 부드럽게 **'심호흡 유도형 3초 서행 진동 파도(Breathe Haptic Wave)'**를 흘려보내 생체와 기기가 하나 됨을 햅틱으로 인지시킴.

## 👩‍👦 4. 연령 맞춤형 인센티브 루프 (Targeted Incentive Loops)

도파민 자극을 회원님의 연령대/배경(남녀노소)의 특성에 맞춰 차별화한 행동 자극 루프 기획 사양입니다.

### 🍭 A. 아동/청소년 트랙 (Parent-Child Reward Link)
- **도파민 자극**: 아이들이 틈새 단어 암기를 성공하거나 저녁 퀴즈를 통과할 때마다 요술봉 효과음과 함께 **"스마트 캔디 칩(Digital Candy)"** 획득.
- **부모 안심 보상 루프**: 칩을 모으면 부모의 카카오톡으로 자동 알림 발송: *"민준이가 오늘 마법 단어를 3개 용감하게 획득하여 '초콜릿 획득권' 배지를 얻었습니다! 오늘 밤 듬뿍 칭찬해 주세요!"*. 부모의 실제 오프라인 보상(칭찬, 간식)과 가상 보상이 맞물려 아동의 학습 본능을 중독시킵니다.

### 👵 B. 실버 어르신 트랙 (Silver Dementia Prevention Badges)
- **도파민 자극**: 노안 고대비 카드를 마칠 때마다 **"뇌 건강 칩(Brain Health Token)"**이 큰 사운드와 함께 적금 통장에 동전이 쌓이듯 적립되는 8비트 아날로그 비주얼 연출.
- **가족 카톡방 브래깅 (Family Pride)**: 할머니의 치매예방 뇌력 종합 점수가 올라가면 가족 카카오톡 단체방에 **"박옥순 할머님의 오늘 뇌 건강 지수가 '젊은이 등급'으로 상승했습니다! 치매 철벽 방어 성공!"** 이라는 효도 알림장이 자랑스럽게 전송되어 가족들의 격려와 효도 칭찬 루프 형성.

### 👩‍💼 C. 직장인/취준생 트랙 (Voice Unlock & Streak Combo)

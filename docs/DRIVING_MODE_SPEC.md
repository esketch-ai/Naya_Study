# DRIVING MODE SPECIFICATION (운전 안심 모드 아키텍처 및 스토리보드 정의서)

본 규격서는 유저가 운전 중인 상태에서 안전을 100% 보장함과 동시에, 청각적 자극만을 이용해 틈새 학습과 퀴즈를 핸즈프리로 안전하게 이행할 수 있도록 설계된 **"나야~" 플랫폼의 운전 안심 모드(Safe Driving Mode) 설계 정의서**입니다.

---

## 1. 운전 상태 자동 감지 및 활성화 프로토콜 (Automatic Detection)

스마트폰의 화면을 조작하지 않아도 시스템이 스스로 운전 중임을 파악하여 즉각 **"운전 안심 락스크린 모드"**로 강제 전환해야 합니다.

```
       +------------------------------------+
       |   1. ActivityRecognition API       | ---> IN_VEHICLE (차량 탑승 상태 감지)
       +------------------------------------+
                         |
                         v (AND 조건)
       +------------------------------------+
       |   2. Car Bluetooth Connection      | ---> 차량 블루투스 오디오 또는
       +------------------------------------+      Android Auto / Apple CarPlay 연결 감지
                         |
                         v
       +------------------------------------+
       |   "운전 안심 모드 (Driving Mode)"   | ---> 100% 핸즈프리 / 터치 원천 차단
       |            자동 활성화             | ---> 오디오 스피커 채널 차량 스피커 연동
       +------------------------------------+
```

### ⚙️ 네이티브 감지 스펙 (Native APIs)
- **Android**: `ActivityRecognitionClient`에서 `DetectedActivity.IN_VEHICLE` 판정을 받고, `BluetoothDevice` 클래스에서 차량 오디오 블루투스 프로필(HFP - Hands-Free Profile / A2DP) 연결이 확인될 때 트리거.
- **iOS**: `CMMotionActivityManager`에서 `automotive` 상태가 `true`이고, `AVAudioSession`에서 출력 경로가 차량 블루투스 또는 CarPlay로 바뀔 때 즉시 활성화.

## 2. 운전 안심 모드 UI/UX 스토리보드 (Hands-Free Storyboard)

### 🎬 SCENE 01: 운전 중 좀비 노출 팝업 (Driving Zombie Audio Alert)

- **오디오 연출**: 경쾌한 차량 알림 벨소리 송출 후 차량 오디오 스피커로 오디오 안내 100% 실행.

### 🎬 SCENE 02: 운전 중 핸즈프리 음성 퀴즈 (Hands-Free Driving Quiz)
- **상황**: 귀가 운전 중 신호 대기 혹은 정속 주행 시, 밤 10시가 지나 귀가용 오디오 시험이 자동 시작될 때.
- **연계 기술**: 완전 음성 전용 문항 읽기 + 유저 음성 답변 인식(STT).

```
[ 시스템 오디오 안내 ]
"저녁 12문항 스파르타 운전 퀴즈를 시작합니다. 
질문. 'Take it easy'의 올바른 의미는 무엇일까요?
1번. 쉽게 가져가다.
2번. 진정하고 마음을 편하게 먹다.
답변하실 보기를 소리 내어 '1번' 또는 '2번'이라고 말씀해 주세요."

[ 유저 발화: "2번!" ]

[ 시스템 오디오 채점 ]
"정답입니다! 2번 퀴즈로 안전하게 넘어갑니다."
```

## 3. 운전 중 최우선 안전 장치 (Safety Rules & Override)

> [!CAUTION]
> 복잡한 도로 상황(네비게이션 안내 겹침, 차선 변경, 돌발 상황)에서 좀비 음성이 계속 나오면 운전자의 집중에 지장을 초래해 매우 위험합니다.

### 🔇 1. 긴급 무음 음성 단어 차단 (Voice Override Cancel)
- 운전 도중 영어 음성이 울릴 때, 운전자가 신경을 써야 하거나 조용히 시켜야 한다면 언제든 크게 **"시끄러워!", "조용히 해!", "스톱!", "Mute!"** 라고 외치면 마이크 수신 엔진이 이를 캐치하여 즉각 오디오를 즉시 중단(Mute)하고 좀비 모드를 슬립 상태로 변환합니다.

### 🔇 2. 내비게이션 보이스 오디오 덕킹 (Audio Ducking Integration)
- T맵, 카카오내비, 네이버 지도 등 내비게이션 앱에서 *"300미터 앞 우회전입니다"* 하고 안내 멘트가 나오는 순간, "나야" 영어 오디오 음량이 자동으로 **10% 수준으로 즉시 감쇠(Ducking)**되어 내비게이션 안내를 완벽하게 들을 수 있도록 교통안전 우선 오디오 믹싱 구조를 탑재합니다.

## 🙋 운전 안심 모드 기획 승인

차량 탑승 및 블루투스 연동 자동 감지, 터치 전면 차단 화면 구성, 완전 음성 퀴즈 제어 및 **'조용히 해! 스톱!' 긴급 무음 오버라이드 장치**와 **'내비게이션 안내 시 자동 오디오 감쇠(Ducking)'**를 결합하여 운전 중에도 한치 오차 없이 안전하고 스마트하게 작동하는 최적의 운전 안심 모드 기획이 완비되었습니다.

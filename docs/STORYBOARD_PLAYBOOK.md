# STORYBOARD & INTEGRATION PLAYBOOK (스토리보드 및 기획 검증 정의서)

본 문서는 "나야~ 영어" 및 통합 과목 플랫폼의 디바이스 간 연계 과정, 흐름상의 결함, 누락된 UX 요소를 정밀 검증하기 위해 작성된 **사용자 시나리오 기반 스토리보드 및 연계 검증서**입니다.

---

## 1. 가상 페르소나 및 라이프사이클 환경 설정
- **사용자**: 김민수 (32세, IT 대기업 3년 차 개발자)
- **목표**: 일상 회화 영어 습득 및 스피킹 자신감 획득
- **장비**: 안드로이드 스마트폰 (Galaxy S24 Ultra) + 스마트워치 (Wear OS)
- **일과 스케줄**:
  - 07:00 기상 및 준비
  - 08:00 지하철 출근 (대중교통 이동)
  - 12:30 점심 식사 후 커피숍 휴식
  - 18:30 지하철 퇴근
  - 22:00 귀가 및 휴식 (저녁 시험)
  - 23:30 취침

## 2. 시간대별 연계 스토리보드 및 와이어프레임 (Step-by-Step Storyboard)

### 🎬 SCENE 01: 오전 07:05 - 상쾌한 기상 직후 잠 깨우기 (Wakeup Trigger)
사용자가 기상 알람 소리를 끄고 스마트폰의 락스크린을 처음 해제하는 순간 작동합니다.

#### 📱 UI/UX 화면 설계 (Lockscreen Zombie Overlay View)
```
+--------------------------------------------------------+
| [07:05 AM]                     [Active Voice: HYPE STAR] |
|                                                        |
|    (⚡) WAKING UP DETECTED!                             |
|    "잠든 뇌세를 깨울 락스타 주입 완료!"                |
|                                                        |
|    +----------------------------------------------+    |
|    |  [Category: KEY PHRASE]                      |    |
|    |                                              |    |
|    |  "Rise and shine!"                           |    |
|    |  [raɪz ænd ʃaɪn]                             |    |
|    |                                              |    |
|    |  뜻: 일어나서 활기차게 시작해봐!              |    |
|    |  예: "Rise and shine, sweetie! School starts"|    |
|    +----------------------------------------------+    |
|                                                        |
|      [ ▶ ] Hype Star Voice로 소리 내어 듣기            |
|      (음량이 쾌활하고 빠른 템포로 자동 재생됩니다.)    |
|                                                        |
|    +----------------------------------------------+    |
|    |          [  이해 완료 및 화면 닫기  ]        |    |
|    +----------------------------------------------+    |
+--------------------------------------------------------+
```
- **디바이스 간 연계 흐름**:
  1. `AlarmManager`가 오전 7시 정각 알람을 울림.
  2. 사용자가 알람을 끄고 화면을 켬 (`ACTION_SCREEN_ON` 방송 수신).
  3. 앱 백그라운드가 기상 유휴 시간으로 판정하고 `ZombieOverlayActivity`를 실행.
  4. 락스타(Energetic) 보이스 톤으로 설정된 오디오 스트림 자동 재생.

### 🎬 SCENE 02: 오전 08:15 - 만원 지하철 내 대중교통 이동 (Transit Trigger)
사용자가 출근 지하철에 탑승하여 흔들림과 이동 속도가 유지되는 순간입니다.

#### 📱 UI/UX 화면 설계 (High-Contrast Large Font View)
```
+--------------------------------------------------------+
| [08:15 AM]                     [Active Voice: SECRETARY]|
|                                                        |
|    (🚌) TRANSIT DETECTED!                              |
|    "출근길 틈새 10초 나포!"                            |
|                                                        |
|    +----------------------------------------------+    |
|    |  [Category: BUSINESS ENGLISH]                |    |
|    |                                              |    |
|    |  "Kill two birds                             |    |
|    |   with one stone"                            |    |
|    |                                              |    |
|    |  뜻: 일석이조, 일거양득                      |    |
|    +----------------------------------------------+    |
|                                                        |
|      [ ▶ ] Secretary Voice (차분하고 또박또박한 비서)   |
|                                                        |
|    +----------------------------------------------+    |
|    |          [  이해 완료 및 화면 닫기  ]        |    |
|    +----------------------------------------------+    |
+--------------------------------------------------------+
```
- **디바이스 간 연계 흐름**:
  1. 스마트폰 내부 `ActivityRecognitionClient`가 3분 이상 `IN_VEHICLE` 상태임을 캐치.
  2. 사용자가 메신저를 확인하기 위해 스마트폰 화면을 켜는 순간, 오버레이 가동.
  3. 흔들리는 만원 지하철 내 피로도를 감안하여 **텍스트 크기가 1.5배 확장되고 배경 명도 대비가 고대비**로 자동 전환됨.
  4. 소음 환경을 감안하여 이어폰(Bluetooth Audio)이 연결된 경우에만 자동으로 또박또박한 비서 목소리로 영어 예문 재생.

### 🎬 SCENE 03: 오후 12:45 - 식사 후 커피숍 대기 중 스트레스 감지 (Wearable Sync Trigger)
회사에서 미팅 후 스트레스가 일시적으로 극심해진 김민수 회원이 커피숍에 앉아 멍을 때리는 순간입니다.

#### 📱 UI/UX 화면 설계 (Wearable Device & Smart Overlay View)
```
+--------------------------+     +--------------------------------------------------------+
|      [ SMARTWATCH ]      |     | [12:45 PM]                         [Active Voice: LOVER] |
|                          |     |                                                        |
|  (❤️) 105 BPM            |     |    (❤️) HIGH STRESS DETECTED (82%)                      |
|  STRESS: 82%             | --> |    "지친 자기의 마음을 녹여줄 Lover 보이스 매칭"       |
|  [ detected: STILL ]     |     |                                                        |
|                          |     |    +----------------------------------------------+    |
|  "BLE 스트레스 패킷 송출"|     |    |  [Category: DAILY EXPRESSION]                |    |
|                          |     |    |                                              |    |
|                          |     |    |  "Under the weather"                         |    |
|                          |     |    |                                              |    |
|                          |     |    |  뜻: 컨디션이 저조한, 찌뿌둥한               |    |
|                          |     |    +----------------------------------------------+    |
|                          |     |                                                        |
|                          |     |      [ ▶ ] Lover Voice (느리고 속삭이는 연인 보이스)   |
|                          |     |      "자기야, 힘들지? 편하게 쉬면서 들어요..."        |
+--------------------------+     +--------------------------------------------------------+
```
- **디바이스 간 연계 흐름**:
  1. 워치의 가속도 센서가 10분간 `STILL` 상태를 유지하여 휴식 시간으로 간주, PPG 광학 센서를 켜서 HRV(심박 변이도) 측정.
  2. RMSSD 수치가 18ms로 떨어져 스트레스 지수 **82%(극도 불안)**로 판정. 워치가 BLE GATT 속성으로 모바일에 송출.
  3. 스마트폰 앱이 스트레스 임계치(75%) 돌파를 인지하고 **음성 채널을 '다정한 연인(Lover)'으로 자동 변환**.
  4. 커피숍 Wi-Fi 연결을 감지하여 틈새 좀비 노출 가동. 부드럽고 템포가 느린 힐링 멘트와 위로 오디오 재생.

## 3. 기획 사각지대(Edge Cases) 및 누락 요소 정밀 검증 (Verification Checklist)

스토리보드를 구성해 흘려보낸 결과, 다음 **5가지 설계상의 치명적 사각지대와 해결책**을 검출했습니다.

### 🔍 1. 오디오 음성 재생 시 공공장소 에티켓 미비 (오디오 텃세)
- **문제점**: 도서관, 만원 지하철, 공공장소에서 좀비 노출 팝업이 활성화될 때 갑자기 폰 스피커로 *"Kill 두 버즈 위드 원 스톤!"* 하고 음성이 울려 퍼지면 사용자는 극도의 당혹감을 느끼고 즉시 앱을 삭제하게 됨.
- **해결책 (UX 보완)**: 
  - 모바일 OS의 **'헤드폰/이어폰 감지 API'**를 작동시킵니다.
  - 이어폰이 연결되지 않은 상태에서는 음성을 자동으로 **무음(Mute)** 처리하고, 화면 카드의 텍스트만 보여줍니다.
  - 사용자가 화면 내의 재생 `[ ▶ ]` 버튼을 명시적으로 눌렀을 때만 미디어 볼륨 크기에 맞춰 음성을 출력하도록 강제 장치를 둡니다.

### 🔍 2. 스마트워치 블루투스 수신 데이터 유실 대책 (데이터 단절)
- **문제점**: 폰을 가방에 넣어두어 블루투스 연결이 일시 단절되거나 워치 전원이 꺼진 경우, 생체 데이터 기반 보이스 변화 로직이 정지되어 앱의 몰입도가 깨짐.
- **해결책 (네이티브 보안)**:
  - 단말기 로컬 DB에 **'최근 생체 스트레스 지수 평균값'**을 캐싱합니다.
  - 최신 30분 이내의 유효 데이터가 없을 경우, 사용자의 역대 평균 스트레스 시간대 스펙을 계산하여 가상의 **'예측 스트레스 수준'**을 모델링하여 세션을 자연스럽게 이어가게 합니다.

### 🔍 3. 5분 프리토킹 중 유저 발화 오디오 무한 침묵 (Silent Lock)
- **문제점**: 사용자가 프리토킹 중 영어가 생각나지 않아 10초 이상 마이크에 아무 말도 하지 않고 침묵할 경우, STT 리스너가 대기 상태로 락(Lock)에 빠져 세션이 굳어버림.
- **해결책 (대화 진행 가이드)**:
  - 유저 발화 침묵이 5초를 돌파하면, 현재 매칭된 보이스 페르소나가 먼저 다정하게 가이드를 제시합니다.
  - *예 (Lover Voice): "자기야, 말하기 부끄러우면 나를 따라 해봐! 'Under the weather' 라고 속삭여볼까?"* 라며 화면에 힌트 텍스트 단추를 띄워 대화가 흐르게 보정합니다.

### 🔍 4. 신규 과목 확장 시 UI 아이덴티티 일관성 (나야 수학 등)
- **문제점**: {나야 수학} 채널이 켜졌는데도 에메랄드 그린 좀비 몬스터 비주얼만 나오면 수학이라는 학문의 성격과 결합되지 않고 이질감이 발생함.
- **해결책 (다과목 테마 가이드)**:
  - 과목 코드(`subject_code`)에 맞춰 앱의 **메인 Accent HSL 테마 컬러**와 백그라운드 일러스트 캐릭터를 동적으로 전환합니다.
    - **영어 (ENGLISH)**: 에메랄드 그린 + 좀비 몬스터 비주얼 (좀비처럼 물고 늘어지는 습관 회화)
    - **수학 (MATH)**: 일렉트릭 블루 + 아인슈타인/뉴턴 가상 멘토 비주얼 (냉철한 이성과 완벽한 논리)
    - **화학 (CHEMISTRY)**: 네온 핑크/오렌지 + 플라스크 분자 비주얼 (신비롭고 정교한 결합 에너지)
